# Vibe code projects

Small single-file tools made with Claude Code.

## notes-and-todo

`notes-and-todo/notes.html`: a notes and to-do app in one HTML file. It uses Courier text and comes with 8 themes (Pitch Black, Jade Green, Jade Black, White, Amber, Midnight, Violet, Sepia).

- Organise notes and to-do lists into sections with headings.
- **Notes are saved inside the HTML file itself.** Open the file in Chrome or Edge and click **Link this file** once. After that, every change is written into `notes.html`.
- To share, send someone the file. Use **Download blank copy** if you want to give them an empty one.
